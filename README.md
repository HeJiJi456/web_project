Веб-приложение «Книжная Полка»

Интерактивное веб-приложение для оптимизации и автоматизации учета личной коллекции книг, созданное в рамках итогового проекта. Приложение имеет полностью клиентскую архитектуру и не требует серверной базы данных.

Цели и задачи проекта
Цель: Создать удобный и интуитивно понятный интерфейс для управления личной коллекцией книг.
Задачи:
Обеспечить возможность добавления новых книг в интерактивный список.
Реализовать функционал для отметки выданных или забронированных книг.
Разработать систему фильтрации литературы по жанрам, авторам или названиям.

Целевая аудитория и особенности
Проект ориентирован на студентов, книголюбов и исследователей, которым необходим быстрый доступ к своему списку литературы и сохранение заметок. 

Ключевые фичи для пользователей:
Темная тема — снижает нагрузку на зрение, обеспечивая комфортное чтение в ночное время суток.
Адаптивная верстка — корректное отображение интерфейса на любых мобильных устройствах, планшетах и ПК.

 Структура и содержание приложения
1. Главная страница:Содержит строку динамического поиска и панель фильтров.
2. Каталог: Представлен в виде сетки из карточек книг (визуальная обложка, название, автор, текущий статус).
3. Личный кабинет / Избранное: Персональный раздел со списком отложенных пользователем книг.

 Функциональные возможности (JS Logic)
Полные CRUD-операции: Добавление, редактирование и удаление данных о книгах без участия бэкенда.
Динамический поиск: Мгновенная фильтрация карточек в каталоге прямо в процессе ввода названия.
Интерактивный статус: Изменение статуса книги («Забронировано» / «Доступна») в один клик без перезагрузки веб-страницы.
Локальное сохранение данных: Полная независимость от сервера благодаря интеграции с Local Storage.
